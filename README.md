# CHES-SD
`in development` <br>
* A 2D pixel-art chess game developed in hardcode **Java**.
* CHES-SD is a simple 2D chess game that features **super deformed** character pieces.

## Features

* SD characters
* Chess Game System
* Two-player mode
* Pixel art animations 
* Custom music and sound effects
* Pixel-art graphics

## How to Run

### Requirements

* Java JDK 17 or newer
* Windows / Linux / macOS

### Running the Game

1. Clone the repository:

```bash
git clone https://github.com/yourusername/ches-sd.git
```

2. Open the project in your preferred Java IDE.

3. Compile and run the main class:

```text
Ches_SD.java
```
